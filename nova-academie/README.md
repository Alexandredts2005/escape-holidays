# NOVA Académie (prototype archivé)

Premier prototype : jeu de télé-crochet au château (VN + rythme + quiz + multijoueur), Phaser 3.
Lancer : `cd nova-academie && npm install && npm start` puis http://localhost:3000

Assets : décors CC0 Poly Haven, personnages CC0 OpenGameArt, sons CC0 Kenney, musique originale générée (`tools/`).
